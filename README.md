# ctmmlearn
ctmm learning materials

To download, click the green "Code" button and then click "Download ZIP".

---

**File Navigation:**

| | |
|---|---|
| `ctmm_glossary.html` | Working glossary for terms and concepts related to animal movement modeling and the `ctmm` package |
| `ctmm_glossary.Rmd` | Development Markdown document for the working glossary |
| html | Contains knitted HTML files for all vignettes available |
| vignettes | Contains Markdown (.Rmd) files for all vignettes available |
| scripts | Contains working scripts for all vignettes available, earlier versions of learning materials, and scripts without corresponding vignettes |
